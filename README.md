# 🌟 영어과외 전용 학습 관리 & 테스트 캘린더 시스템

영어과외 학생 6명의 테스트 일정, 본시험/재시험 통과 여부, 커트라인 및 상세 피드백을 체계적으로 관리할 수 있는 맞춤형 웹 애플리케이션입니다.

---

## 📌 주요 기능 안내

### 1. 학생 프로필 선택 (메인 화면)
- 6명의 학생 프로필 카드 중 본인 프로필을 자유롭게 선택하여 입장할 수 있습니다.
- 카드에서 이번 달 전체 시험 수, 통과 횟수, 재시험 대기 건수 및 다음 시험 D-Day를 미리 확인할 수 있습니다.

### 2. 학생별 인터랙티브 캘린더 & 상세 정보 뷰
- **월간 캘린더**: 월별 시험 일정과 재시험 일정을 달력에서 한눈에 확인.
- **색상별 상태 배지**:
  - 🟢 **초록색**: 본시험 통과 또는 재시험 합격 (PASS)
  - 🟡 **주황색**: 재시험 대기 (RETEST PENDING)
  - 🔴 **빨간색**: 불합격 (FAIL)
  - 🔵 **파란색**: 시험 예정 (SCHEDULED)
- **시험 상세 모달 (일정 클릭 시)**:
  - 📅 시험 일시 및 D-Day
  - 🎯 시험 범위 및 상세 안내
  - 📊 커트라인(기준점수) 및 본인 획득 점수
  - 🏆 1차 본시험 통과 여부
  - 🔄 재시험 통과 여부 및 재시험 일자
  - 💬 선생님의 1:1 맞춤 피드백 & 복습 가이드
- **리스트형 뷰 탭**: 캘린더 외에 [전체 / 예정 / 통과 / 재시험] 필터로 모아보기 지원.

### 3. 선생님 관리자 모드 (`Admin`)
- **관리자 비밀번호**: `090927`
- **시험 일정 및 성적 관리**:
  - 새 시험 일정 등록 및 수정 / 삭제
  - 원클릭 상태 변경 버튼 (본시험 통과/불합격/대기, 재시험 통과/탈락/대기/해당없음)
  - 커트라인, 학생 점수, 시험 범위, 피드백 코멘트 관리
- **전체 6명 학생 종합 현황판**: 6명 학생의 통과율, 다음 시험, 재시험 건수를 매트릭스로 비교.
- **학생 프로필 정보 수정**: 학생 이름 및 학습 목표를 자유롭게 수정 가능.
- **데이터 백업 및 복원**:
  - `JSON 다운로드`: 현재 데이터를 파일로 백업
  - `JSON 가져오기`: 백업 파일로 데이터 즉시 복원
  - `기본 샘플 데이터 리셋`: 초기 테스트 데이터로 초기화

## 🚀 실행 방법

별도의 서버 설치나 빌드 과정 없이 `index.html` 파일을 크롬(Chrome), 사파리(Safari), 엣지(Edge) 등 브라우저로 열면 바로 작동합니다.

- **로컬 실행**: `index.html` 더블 클릭
- **데이터 저장**: Firebase Cloud Firestore에 자동 저장되어 기기와 브라우저가 달라도 같은 데이터를 실시간으로 확인할 수 있습니다.
