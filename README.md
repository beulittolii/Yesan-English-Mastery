# 🌟 영어과외 전용 학습 관리 & 테스트 캘린더 시스템

영어과외 학생 6명의 테스트 일정, 본시험/재시험 통과 여부, 커트라인 및 상세 피드백을 체계적으로 관리할 수 있는 맞춤형 웹 애플리케이션입니다.

---

## 📌 주요 기능 안내

### 1. 학생 프로필 선택 (메인 화면)
- 6명의 학생 프로필 카드 중 본인 프로필을 자유롭게 선택하여 입장할 수 있습니다.
- 카드에서 이번 달 전체 시험 수, 통과 횟수, 재시험 대기 건수 및 다음 시험 D-Day를 미리 확인할 수 있습니다.

### 2. 학생별 인터랙티브 캘린더 & 상세 정보 뷰
- **월간 캘린더**: 월별 시험 일정과 재시험 일정을 달력에서 한눈에 확인.
- **색상별 상태 배지**:
  - 🟢 **초록색**: 본시험 통과 또는 재시험 합격 (PASS)
  - 🟡 **주황색**: 재시험 대기 (RETEST PENDING)
  - 🔴 **빨간색**: 불합격 (FAIL)
  - 🔵 **파란색**: 시험 예정 (SCHEDULED)
- **시험 상세 모달 (일정 클릭 시)**:
  - 📅 시험 일시 및 D-Day
  - 🎯 시험 범위 및 상세 안내
  - 📊 커트라인(기준점수) 및 본인 획득 점수
  - 🏆 1차 본시험 통과 여부
  - 🔄 재시험 통과 여부 및 재시험 일자
  - 💬 선생님의 1:1 맞춤 피드백 & 복습 가이드
- **리스트형 뷰 탭**: 캘린더 외에 [전체 / 예정 / 통과 / 재시험] 필터로 모아보기 지원.

### 3. 선생님 관리자 모드 (`Admin`)
- **관리자 비밀번호**: `090927`
- **시험 일정 및 성적 관리**:
  - 새 시험 일정 등록 및 수정 / 삭제
  - 원클릭 상태 변경 버튼 (본시험 통과/불합격/대기, 재시험 통과/탈락/대기/해당없음)
  - 커트라인, 학생 점수, 시험 범위, 피드백 코멘트 관리
- **전체 6명 학생 종합 현황판**: 6명 학생의 통과율, 다음 시험, 재시험 건수를 매트릭스로 비교.
- **학생 프로필 정보 수정**: 학생 이름 및 학습 목표를 자유롭게 수정 가능.
- **데이터 백업 및 복원**:
  - `JSON 다운로드`: 현재 데이터를 파일로 백업
  - `JSON 가져오기`: 백업 파일로 데이터 즉시 복원
  - `기본 샘플 데이터 리셋`: 초기 테스트 데이터로 초기화

### 4. 문법 테스트

- 시험 관리의 `문법 테스트 추가`에서 학생과 응시 일정을 지정합니다. 가정법 최초 배정은 개념과 실전을 함께 출제합니다.
- 개념은 원문을 옮긴 빈칸 시험지입니다. 빈칸을 남기고 넘어가면 미입력 개수를 확인하며, 실전 진입 후 개념은 수정할 수 없습니다.
- 실전은 5지선다 10문제이며, 마지막 문항에서 제출할 수 있으며, 미응답 문항이 있으면 개수를 확인한 뒤 제출합니다. 제출 즉시 점수와 80점 통과 여부가 표시됩니다.
- 개념은 `결과 / 채점`에서 일치 답안은 자동 정답 처리하고 다른 답안만 검토합니다. 미입력은 오답이며 전체 빈칸 수에 포함합니다. 개념과 실전은 각각 80점 이상 통과입니다.
- 재시험은 선생님이 미달한 영역만 새로 배정합니다. 기존 성적과 응시 이력은 유지합니다.
- 응시 중 임시 저장·이어 풀기를 제공하지 않습니다. 개념 제출과 최종 제출 때 답안을 저장하며, 저장 실패 시 같은 화면에서 다시 제출할 수 있습니다.
- 응시 시작부터 최종 제출까지 돌아가기·로고·로그아웃 등 앱 내 이동과 브라우저 뒤로가기를 차단합니다. 새로고침·탭 닫기에는 브라우저 기본 이탈 경고를 표시합니다. 브라우저가 강제 종료를 허용하면 앱에서 이를 완전히 막을 수는 없습니다.

### 5. 토요일 주간 단어 복습

- 월~금 매일 배정된 단어 시험이 모두 최종 통과하면 토요일 `주간 복습`이 자동 생성됩니다. 통합 시험은 관리자 채점까지 완료해야 합니다. 접속·응시·채점 후 확인하며 서버 예약 작업은 사용하지 않습니다.
- 한국 시간 토요일 00:00부터 응시하며, 늦게 평일 시험을 끝내도 해당 주차 복습을 계속할 수 있습니다.
- 해당 주 오답 최대 30개와 한 번도 틀리지 않은 정답 단어 최대 10개를 출제합니다. 이전 재시험 오답도 포함하며 오답이 없으면 생략합니다. 원본과 정확히 연결할 수 없는 기록은 출제하지 않고 관리자에게 자료 확인 상태를 표시합니다.
- 뜻 오답은 5지선다, 스펠링 오답은 영어 입력입니다. 회차 제출 후 오답만 반복하며 모두 해결하면 완료됩니다. 첫 점수는 유지하고 커트라인·제한시간·재응시 대기시간은 적용하지 않습니다.
- 중도 이탈에 불이익이 없으며 마지막 제출 회차부터 이어갑니다. 작성 중인 미제출 답안은 저장하지 않습니다.
- 생성 문항·원본 연결은 시험 문서에 고정하고 진행 기록은 기존 권한이 적용되는 시험 문서의 `weeklyReviewResult`에 별도 보관합니다. JSON 백업·복원에 포함되며 기존 단어 성적은 변경하지 않습니다.

주간 복습 로직 테스트: `node --test tests/weekly-review.test.cjs`

주간 복습 브라우저 테스트: `node tests/weekly-review-browser.cjs` (Playwright 및 Chrome 필요, `TAILWIND_SCRIPT_PATH`로 로컬 Tailwind 스크립트 지정 가능). 실제 Firebase 대신 격리된 트랜잭션 저장소를 사용합니다.

문법 로직 테스트: `node --test tests/grammar.test.cjs`

브라우저 테스트: Playwright가 설치된 환경에서 `node tests/grammar-browser.cjs`. 실제 Firebase에 연결하지 않는 격리된 테스트입니다. 필요하면 `NODE_PATH`와 `CHROME_PATH`로 Playwright 설치 위치와 Chrome 실행 파일을 지정할 수 있습니다.

## 🚀 실행 방법

별도의 서버 설치나 빌드 과정 없이 `index.html` 파일을 크롬(Chrome), 사파리(Safari), 엣지(Edge) 등 브라우저로 열면 바로 작동합니다.

- **로컬 실행**: `index.html` 더블 클릭
- **데이터 저장**: Firebase Cloud Firestore에 자동 저장되어 기기와 브라우저가 달라도 같은 데이터를 실시간으로 확인할 수 있습니다.
