학교 내신 성적표

학기별 내신 성적을 기록하고, 이수단위 가중평균 등급을 실시간으로 확인하세요.

상대평가 과목 성적표 (석차 5등급제)

석차 1~5등급이 산출되며 대입 가중평균 GPA에 반영되는 교과목입니다. (2022 개정 5등급제 기준)

전국 모의고사 성적 관리

전국연합학력평가(교육청), 모의평가(평가원/수능) 및 사설 모의고사 성적을 체계적으로 기록하고 관리하세요.

목표 대학 및 학과 (1·2·3지망)

1·2·3지망 희망 대학/학과와 목표 등급을 설정하고 나의 현재 성적과 한눈에 비교해 보세요.

입시 목표 달성 전략 가이드

현재 1지망 대학 합격을 위해 가장 중요한 것은 전과목 내신 등급 유지와 수능 최저학력기준 충족입니다. 수행평가 감점을 최소화하고 정기 모의고사로 실전 감각을 키워보세요!

현재 등록된 모든 학생 정보 및 시험 일정/결과 데이터를 JSON 파일로 내보내 안전하게 보관합니다.

데이터 복원 (JSON 가져오기)

이전에 백업해둔 JSON 파일을 불러와 시험 일정 및 학생 데이터를 즉시 복원합니다.

기본 샘플 데이터로 리셋

모든 변경 사항을 초기화하고 처음 제공된 6명 학생의 풍부한 샘플 시험 데이터로 되돌립니다.

학업관리 데이터 클라우드 동기화 및 관리

수행평가, 내신 성적, 모의고사, 목표대학 데이터를 Firebase 클라우드와 수동 동기화하거나 초기화합니다.

클라우드로 즉시 업로드

현재 이 브라우저에 저장된 학업관리 데이터를 Firestore 클라우드에 강제로 업로드합니다. (다른 기기 및 학생 화면에 즉시 동기화)

클라우드에서 최신 불러오기

Firestore 클라우드에 저장된 최신 학업관리 데이터를 내려받아 이 브라우저의 화면과 로컬 스토리지를 갱신합니다.

학업 데이터 비우기 / 샘플

기존 더미/샘플 데이터를 완전히 삭제하여 깨끗한 상태로 비우거나, 테스트를 위해 샘플 데이터를 채울 수 있습니다.
